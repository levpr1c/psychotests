# PsychoTests

Современное TUI-приложение с 9 психологическими тестами, воссозданное путём реверс-инжиниринга оригинальных DOS-программ 1990-х годов.

## Тесты

| Тест | Что измеряет | Вопросов |
|------|-------------|----------|
| **Биоритмы** | Физический (23д), эмоциональный (28д), интеллектуальный (33д) циклы | По дате |
| **Айзенк EPI** | Экстраверсия (24), нейротизм (24), шкала лжи (9) | 57 Да/Нет |
| **Стресс** | Уровень стресса | 24 × 1-5 |
| **Неврология** | Неврологическое состояние | 24 × 1-5 |
| **Совместимость** | Межличностная совместимость | 25 × 1-5 |
| **Деловая сфера** | Деловая ориентация | 25 × 1-5 |
| **Сердечно-сосуд.** | Сердечно-сосудистые тенденции (IBC/PPS/DE/AG/NCD/ZM) | 25 × 1-5 |
| **Самооценка** | Уровень самооценки | 20 × 1-5 |
| **Люшер** | Цветовой тест личности (тревога, компенсация, активность, работоспособность) | 8 цветов × 2 раунда |

## Быстрый старт

```bash
pip install -r requirements.txt
python3 run.py
```

Зависимости: Python 3.14+, Textual 8.x, Pydantic 2.x, Rich.

### Управление

| Клавиша | Действие |
|---------|----------|
| `q` / `й` | Выход (с подтверждением) |
| `escape` | Назад |
| `1`–`5` | Выбрать ответ (тесты 1-5) |
| `enter` | Далее |
| `↑↓←→` | Навигация / переключение радио-кнопок |

Возможности: управление пользователями, статистика с диаграммами и история тестов (SQLite), русский интерфейс.

## История создания: реверс-инжиниринг

Оригинальный сборник «Сборка прог по психологии» — это DOS-пакет середины 1990-х, содержащий 8 COM-файлов, скомпилированных в **Turbo Pascal**, и EXE для цветового теста Люшера. Исходный код и внешняя база вопросов (`CODE.DAT`) были утеряны — сохранились только бинарники.

### Фаза 1: Анализ бинарников

Hex-анализ COM-файлов выявил общую сигнатуру рантайма (`e9 79 2c 90 cd ab 20 20`) и единую структуру: стартовый код Turbo Pascal, затем перемежающиеся данные и код программы. Программы использовали `CODE.DAT` — бинарный файл из 256 записей (240 вопросов + 16 служебных записей с параметрами: ключи шкал, маски инверсии, коэффициенты нормализации), который отсутствовал в архиве.

Цветовой тест Люшера (`LUSHER.EXE`) оказался MS-DOS MZ-исполняемым с собственными файлами данных: `LUSHER.DAT` (бинарная БД испытуемых), `LUSHER.INT` (тексты интерпретаций в CP866) и `LUSHER.CAT` (каталог испытуемых). Эти файлы сохранились и читались напрямую.

### Фаза 2: Восстановление банков вопросов

Поскольку `CODE.DAT` отсутствовал, каждый банк вопросов восстанавливался следующим образом:
- **Айзенк EPI**: 57 стандартных вопросов EPI (русскоязычная адаптация), ключи шкал по опубликованной методике
- **Стресс/Неврология/Совместимость/Деловая сфера/Сердечно-сосуд./Самооценка**: опросники по шкале Ликерта (24 или 25 вопросов), восстановленные по косвенным признакам параметров в COM-бинарниках — количество вопросов, паттерны инверсии, количество шкал
- **Биоритмы**: чистый расчёт (синусоидальные циклы), банк вопросов не требовался
- **Люшер**: 8 цветов, 2 раунда — логика извлечена из EXE трассировкой цепочки выбор → баллы → интерпретация

Тексты интерпретаций были восстановлены из оригинальных DOS-строк в бинарниках и из файла `LUSHER.INT`.

### Фаза 3: Создание TUI

Python TUI построен на **Textual** (Rich-based терминальный UI-фреймворк):
- `_base_test.py` — переиспользуемый экран для тестов Ликерта (радио-кнопки 1-5)
- Отдельные экраны для Айзенка (2 кнопки Да/Нет), Биоритмов (ввод даты), Люшера (выбор цвета)
- SQLite3 для постоянного хранения, Pydantic для валидации моделей
- Навигация стрелками, `q`/`escape` для выхода, русскоязычный интерфейс

Полный отчёт о реверс-инжиниринге с mermaid-диаграммами: [`docs/analysis.md`](docs/analysis.md). Документация разработчика: [`docs/development.md`](docs/development.md). Руководство по коду: [`docs/code-guide.md`](docs/code-guide.md).

### Создано нейросетью

Весь проект — включая реверс-инжиниринг, Python-код, тесты и документацию — был сгенерирован большой языковой моделью (OpenCode). Человек предоставил оригинальные DOS-бинарники и сформулировал требования; нейронная сеть сделала всё остальное.
