# PsychoTests

TUI-приложение с 9 психологическими тестами, воссозданное по оригинальным DOS-программам (1990-е).

## Тесты

| Тест | Что измеряет | Вопросов |
|------|-------------|----------|
| **Биоритмы** | Физический, эмоциональный, интеллектуальный циклы | По дате |
| **Айзенк EPI** | Экстраверсия, нейротизм, шкала лжи | 57 Да/Нет |
| **Стресс** | Уровень стресса | 24 × 1-5 |
| **Неврология** | Неврологическое состояние | 24 × 1-5 |
| **Совместимость** | Межличностная совместимость | 25 × 1-5 |
| **Деловая сфера** | Деловая ориентация | 25 × 1-5 |
| **Сердечно-сосуд.** | Сердечно-сосудистые тенденции (6 шкал) | 25 × 1-5 |
| **Самооценка** | Уровень самооценки | 20 × 1-5 |
| **Люшер** | Цветовой тест личности | 8 цветов × 2 раунда |

## Запуск

```bash
pip install -r requirements.txt
python3 run.py
```

| Клавиша | Действие |
|---------|----------|
| `q` / `й` | Выход |
| `escape` | Назад |
| `1`–`5` | Выбрать ответ |
| `enter` | Далее |
| `↑↓←→` | Навигация |

Возможности: управление пользователями, история тестов, русский интерфейс.

## Reverse Engineering

Исходные DOS-программы были подвергнуты реверс-инжинирингу для извлечения логики тестов, банков вопросов и текстов интерпретаций. Полный отчёт: [docs/analysis.md](docs/analysis.md).
